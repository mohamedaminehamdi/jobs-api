Everything a job tracker needs

Build the app you want on top of it. The API takes care of storing applications, finding them again and keeping each account private.

Keep track of applications
Company, position, status, job type, location, salary range, a link to the posting and your own notes. Every status change is recorded with the time it happened.
Find the one you need
Search by position or company, filter by one or several statuses, job type or date range, then sort and page through the results.
See how the search is going
Counts per status and per job type, plus applications per month. This is the demo account after seeding:
  • 15 pending
  • 10 interview
  • 5 offer
  • 10 declined
Take your data with you
Download any filtered list as CSV. Values that a spreadsheet would run as formulas are escaped.
Keep accounts safe
JWT sessions and bcrypt-hashed passwords. Changing a password signs out every other session, and deleting an account removes all of its jobs. Requests are validated, sanitized and rate limited, and the public demo account is read only.

Endpoints

Everything lives under /api/v1. Send the token from register or login as Authorization: Bearer <token>.

Account
Method Route Does
POST /auth/register Create an account
POST /auth/login Log in
GET /auth/me Your profile
PATCH /auth/updateUser Edit your profile
PATCH /auth/updatePassword Change your password
DELETE /auth/me Delete your account
Jobs
Method Route Does
GET /jobs Search and list
POST /jobs Add an application
GET /jobs/stats Counts and trends
GET /jobs/export Download as CSV
GET /jobs/:id One application
PATCH /jobs/:id Update it
DELETE /jobs/:id Remove it

Run it in four steps

You need Docker. The API comes up on port 3000 with a MongoDB container next to it.

  1. Get the code

    git clone https://github.com/mohamedaminehamdi/Jobs-Api.git
cd Jobs-Api

  2. Start the API and the database

    JWT_SECRET=pick-a-long-random-secret docker compose up --build -d

  3. Load the demo data

    docker compose exec api node populate.js

  4. Log in as the demo user and ask for stats

    TOKEN=$(curl -s localhost:3000/api/v1/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"email":"demo@example.com","password":"demo-password"}' | jq -r .token)

curl -s localhost:3000/api/v1/jobs/stats -H "Authorization: Bearer $TOKEN"
